# Corfu History Walk

אפליקציית ווב סטטית לסיור היסטורי עצמאי בעיר העתיקה של קורפו, בנויה mobile-first לשימוש בשטח.

**אתר חי:** https://ww3.github.io/corfu-history-walk/

## מה יש בה

- **תשע תחנות** עם הסבר היסטורי, זמן מוערך במקום, תמונה אחת לזיהוי המקום ורשימת "מקורות" מתקפלת.
- **שני מסלולים:** המסלול המלא (9 תחנות, כ־4–4.5 שעות) ומסלול מקוצר (5 תחנות, כ־2–2.5 שעות). הבחירה נשמרת בדפדפן.
- **ניווט לתחנה הבאה:** כל תחנה מציגה כפתור "נווטו לתחנה X" שפותח ב־Google Maps מסלול הליכה של מקטע אחד (origin → destination), עם הערכת זמן הליכה. בנוסף יש "נווטו לתחנה זו ממקומכם".
- **המסלול המלא ב־Google Maps** מוצג בשני מקטעים של עד 5 תחנות, כי Google Maps URLs תומכים בעד 3 נקודות ביניים בנייד.
- **התקדמות:** "תחנה 3 מתוך 9", כפתורי קודם/הבא, ותחנה אופציונלית (העלייה למצודה העליונה) מסומנת ככזו.
- **דילוג על תחנה אופציונלית:** בכרטיס התחנה שלפני תחנה אופציונלית מופיע קישור "נווטו ישירות לתחנה X" עם זמן ומרחק הליכה
  אמיתיים של המקטע הישיר (בלי לעבור בתחנה האופציונלית), כדי שאפשר יהיה להשוות ולהחליט בשטח.
- **מפה אינטראקטיבית** (Google Maps JavaScript API) עם סימוני תחנות ו־polyline. בנייד המפה מקופלת כברירת מחדל ונטענת רק כשפותחים אותה.
- **Offline:** service worker שמאחסן את קבצי האפליקציה ואת התמונות; מניפסט להתקנה כ־PWA.

## הפעלה מקומית

```bash
python -m http.server 8080
```

ופתחו `http://localhost:8080`. ב־`localhost` (או עם `?devkey` בכתובת) מופיע בתוך אזור המפה טופס להזנת מפתח Google Maps לפיתוח, שנשמר ב־`localStorage` בלבד. באתר החי הטופס אינו מוצג.

## Google Maps

### מפתח API באתר הפרוס (GitHub Pages)

האתר נפרס דרך GitHub Actions (`.github/workflows/deploy-pages.yml`). בזמן הפריסה, ה־workflow מחליף את ה־placeholder
שב־`config.js` בערך של ה־secret `GOOGLE_MAPS_API_KEY` של המאגר, כך שהמפתח אינו נשמר בקוד המקור או בהיסטוריית git.
באותו שלב מוחלף גם `__BUILD_ID__` שב־`sw.js` ב־SHA של ה־commit, כדי שכל פריסה תרענן את ה־cache של ה־service worker.

הגדרה חד־פעמית:

1. ב־Google Cloud Console: צרו פרויקט, הפעילו **Maps JavaScript API** ו־**Routes API**, וצרו API key.
2. הגבילו את המפתח:
   - **Application restrictions → Websites**: `https://ww3.github.io/*`
   - **API restrictions**: Maps JavaScript API ו־Routes API בלבד.
3. ב־GitHub: Settings → Secrets and variables → Actions → **New repository secret**, בשם `GOOGLE_MAPS_API_KEY`.
4. הריצו מחדש את ה־workflow (או דחפו commit) כדי לפרוס עם המפתח.

מפתח של Maps JavaScript API נחשף בהכרח בדפדפן; ההגנה האפקטיבית היא הגבלת ה־referrer וה־API שלמעלה.
אם המפתח חסר או שגוי, המטייל רואה הודעה קצרה ("המפה האינטראקטיבית אינה זמינה כרגע") עם קישור ניווט לתחנה הבאה — לא מושג ה־API key.

האפליקציה משתמשת ב־Advanced Markers וב־`DEMO_MAP_ID`, כך שאין צורך ב־Map ID פרטי.

## נגישות

- `lang="he"` וכיוון RTL; שמות ומונחים באנגלית עטופים ב־`<span lang="en" dir="ltr">`.
- שני קישורי דילוג: לתחנה הנוכחית ולרשימת התחנות (יעדים עם `tabindex="-1"`).
- רשימת תחנות מלאה שאינה תלויה במפה; ניווט מקלדת מלא.
- התחנה הפעילה מסומנת ב־`aria-current="step"`; כפתורי התחנות עם `aria-controls="stop-detail"`.
- בחירת תחנה מעבירה את המיקוד לאזור התחנה (`region` עם `aria-labelledby`) ומכריזה הודעה קצרה ב־`role="status"`
  ("נבחרה תחנה 4 מתוך 9, …") במקום `aria-live` על כל התוכן.
- כפתור המפה בנייד עם `aria-expanded`/`aria-controls`; הגדלת תמונה ב־`<dialog>` נגיש.
- תמיכה ב־`prefers-reduced-motion`; יעדי מגע של 44px לפחות בנייד.

## תמונות

לכל תחנה תמונה אחת מ־Wikimedia Commons ברישיון חופשי (`images.js`), עם קרדיט ורישיון בכיתוב וקישור לעמוד המקור.
התמונות נטענות ב־lazy loading ונשמרות ב־cache של ה־service worker לאחר הצפייה הראשונה.

## זמני הליכה ומסלול על המפה (Routes API)

בטעינה (ובכל החלפת מסלול) האפליקציה שולחת **בקשת `computeRoutes()` אחת** דרך ה־`Route` class של Maps JavaScript API
(ספריית `routes`, ערוץ `v=beta`), עם כל תחנות המסלול כ־intermediates (עד 7, בתוך שכבת Essentials). מכל `leg` נלקחים
זמן ומרחק הליכה אמיתיים, ומ־`path` מצויר על המפה מסלול ההליכה בפועל במקום קווים ישרים.

- **דילוג על תחנה אופציונלית:** לכל תחנה המסומנת `optional: true` (כיום: העלייה למצודה העליונה) נשלחת בקשה קטנה נוספת,
  ללא intermediates, מהתחנה שלפניה אל התחנה שאחריה. התוצאה מוצגת בכרטיס התחנה הקודמת כקישור
  "מדלגים על התחנה האופציונלית? נווטו ישירות לתחנה X" עם דקות ומטרים. במסלול הנוכחי: דרך המצודה העליונה
  כ־27 דקות ו־1.8 ק״מ, ישירות מכנסיית גאורגיוס הקדוש לפלירקי כ־13 דקות ו־990 מ׳.
- התוצאה (כולל המקטעים הישירים) נשמרת ב־`localStorage`. המפתח כולל את מזהי התחנות **והקואורדינטות** שלהן,
  כך שהזזת תחנה מבטלת אוטומטית את ה־cache הישן; רשומות שאינן תואמות למסלול נוכחי נמחקות בטעינה.
  גם בלי קליטה מוצגים הזמנים האחרונים שחושבו.
- אם Routes API אינו מופעל, הקריאה נכשלת או שאין רשת — האפליקציה חוזרת להערכה מקו אווירי
  (מקדם 1.35, כ־75 מטר לדקה), מסמנת אותה כ־"(הערכה)", והמפה מציגה קווים ישרים בין התחנות.
  אותו fallback חל גם על המקטע הישיר של הדילוג.
- טעינת סקריפט ה־API בלבד אינה נחשבת "map load"; מופע המפה נוצר רק כשהמפה גלויה (בנייד: אחרי "הצג מפה").

## הערה על המסלול וזמנים

זמני ההליכה הם הערכה של Google לקצב הליכה רגיל, בלי עצירות; בסמטאות ובתוך המצודה כדאי להוסיף מרווח.
הזמנים במקום (200–260 דקות במסלול המלא) אינם כוללים הליכה, כניסה למצודה והמתנות; לכן משך הסיור המוצג הוא כ־4–4.5 שעות.
